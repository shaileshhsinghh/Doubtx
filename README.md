📘 DoubtX – Student Doubt-Solving Platform
🚀 DoubtX is a web-based platform built to empower students by providing a space to ask academic questions, receive answers, and stay motivated through a reward system.
Developed as part of a hackathon challenge, DoubtX aims to make peer-to-peer learning more engaging, collaborative, and rewarding.

🔧 Key Features
📩 Students can ask questions and get answers from peers or tutors

🎯 Earn points and unlock cash rewards or courses upon hitting learning milestones

👤 Role-based login (Student / Tutor) with secure credential management

💬 Real-time chat integration using Socket.io

🤖 AI-powered suggestions to guide students as they upload doubts

📂 Organized by department, making it easier to find subject-specific help

🛠 Tech Stack
Frontend: HTML, CSS, JavaScript

Backend: Node.js, Express

Real-time Communication: Socket.io

Storage: File-based (JSON) for user and doubt data

Design: Telegram-inspired modern UI with dark gradient themes
